# Sinhala & Tamil New Year Wish

A creative one-page greeting website for Sinhala and Tamil New Year.

## Publish on GitHub Pages

1. Open your repository settings.
2. Go to **Pages**.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. Go to the **Actions** tab and wait for workflow **Deploy static site to Pages** to finish successfully.

After deployment, your site URL will be shown in the Pages section.

Expected URL:

- https://kavinipremarathna.github.io/newyearwish/

If you still see 404:

1. Confirm the repository is public.
2. Confirm the Pages source is **GitHub Actions**.
3. Re-run the latest workflow from **Actions**.
4. Wait 1-3 minutes and hard refresh the page.
