# Sinhala & Tamil New Year Wish

A creative one-page greeting website for Sinhala and Tamil New Year.

## Publish on GitHub Pages

1. Open your repository settings.
2. Go to **Pages**.
3. Under **Build and deployment**, choose:
   - **Source**: Deploy from a branch
   - **Branch**: `main`
   - **Folder**: `/ (root)`
4. Save.

After deployment, your site URL will be shown in the Pages section.
